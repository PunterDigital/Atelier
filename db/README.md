# Database

Postgres via Drizzle ORM.

- `schema.ts` - the Phase 0 core: `business`, `user`, `client`. Every
  table holding business data carries a `business_id`, and
  `schema.test.ts` fails the gate if a new domain table is added without
  one.
- `index.ts` - lazy `getDb()`; the build and DB-free test suites never
  need a `DATABASE_URL`, anything touching the database fails loud
  without one.
- `migrations/` - generated by `pnpm db:generate`, applied by
  `pnpm db:migrate`. Checked in, never hand-edited.

Connection config comes from `DATABASE_URL` (see `.env.example`).
